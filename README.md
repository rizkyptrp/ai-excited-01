A generative program that draws "The Rocket That Paints the Galaxy": a 1024×1024 poster painted entirely in code — a rocket blasting off a moon base, its trail of light dissolving into a spiral galaxy — with no image assets at all. Deterministic: every run produces the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
